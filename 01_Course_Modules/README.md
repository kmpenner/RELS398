# 01_Course_Modules

One folder per module/week. Follow either the 331 pattern
(`Module_01_Topic_Name`) or the 222 pattern (`Module 1 - Topic Name`,
containing `01_Source_Materials`, `02_Drafts_and_Outlines`, `03_Moodle_Assets`).

`*/01_Source_Materials/` and `*/sources/` are git-ignored by design —
downloaded readings travel via the Drive mirror, not git.
