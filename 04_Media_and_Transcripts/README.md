# 04_Media_and_Transcripts

Audio, video, slide decks, and their transcripts.

The media itself is git-ignored (`*.m4a`, `*.mp4`, `*.pptx`, …) and reaches
other machines through the Drive mirror. The `.txt`/`.md` transcripts beside
it *are* tracked — that is the two-channel split: git for text you author,
Drive for bulk media.
