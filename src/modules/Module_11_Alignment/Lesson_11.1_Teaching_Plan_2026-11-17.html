THE ALIGNMENT DIRECTIVE: STANDOFF ARCHITECTURE FOR BILINGUAL EDITIONS

A digital translation is not an inert paraphrase. By encoding sentence correspondences inside a standoff <linkGrp>, students make every translation decision explicit, verifiable, and computationally accessible.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Produce the target text first (Step 0): You cannot align a translation that does not exist yet. Draft target_translation.xml (interlingual translation or intralingual modern rendering) before writing any links.
2. Use VS Code split editor: Keep source text on the left pane and target_translation.xml on the right pane (View > Editor Layout > Two Columns) to prevent cognitive overload.
3. Standoff linking only: Never paste modern translations directly into the historical manuscript XML tree; preserve both files and link them via <linkGrp>.
4. The hash mark prefix: Every ID inside a @target attribute must be preceded by a hash mark (target="#s1 #t1").
5. Tuesday ground truth baseline: Today's hand-crafted files (target_translation.xml and alignment_manual.xml) establish the gold standard used to audit Wednesday's automated tools and Friday's AI output.
