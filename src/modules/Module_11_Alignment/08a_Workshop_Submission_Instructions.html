Submission Instructions

  1. Select a 10-sentence section of your primary witness text and an authoritative modern translation.
  2. Open both files in a two-column split editor in VS Code (View > Editor Layout > Two Columns).
  3. Align the sentences into parallel pairs (assigning xml:id="s1", xml:id="s2" ... to source sentences, and xml:id="t1", xml:id="t2" ... to target translation sentences).
  4. For 3 sentences, construct a full four-line Leipzig Interlinear Gloss: (Line 1: Source text, Line 2: Morpheme segmentation, Line 3: Grammatical gloss with capitalized category tags and Rule 2 punctuation, Line 4: Free idiomatic translation in quotation marks).
  5. Encode the entire alignment in a TEI XML document utilizing a stand-off <linkGrp type="translation-alignment"><link target="#s1 #t1"/>...</linkGrp> structure.
  6. Submit your reconciled TEI XML files (alignment_reconciled.xml and gloss_reconciled.xml) and a 300–500 word reflection in ALIGNMENT.md discussing your three-way audit findings (Manual vs. Gale-Church vs. AI).
