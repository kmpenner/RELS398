Module 11: Text Alignment & Interlinear Glossing — Learning Objectives

By the end of this module, students will be able to:

  • Construct four-line Interlinear Glossed Text (IGT) adhering strictly to the international Leipzig Glossing Rules, distinguishing morpheme cuts (-) from fused grammatical categories (.).
  • Encode sentence-level parallel alignments in TEI P5 using stand-off <linkGrp> and <link> architecture in Visual Studio Code.
  • Analyze the operational principles of length-based sentence alignment (Gale-Church) using character count ratios and visual alignment matrices.
  • Run a length-based sentence aligner (hunalign in the InterText editor) and audit its raw output against a manual alignment.
  • Audit and evaluate AI-assisted translation alignments, identifying failure modes such as silent spelling modernization, Rule 2 hyphen confusion, and pronoun enclisis slips.
