THE SYNCHRONIZATION DIRECTIVE: EVERY LINK AND ZONE MUST RESOLVE

A parallel edition earns reader trust when every anchor clicks smoothly across image, source text, and translation. One typo in a @target="#s1" or @facs="#z_body_p1" pointer silently breaks interaction—so the viewer's status bar and DevTools Console serve as today's gate before pushing.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Exact xml:id parity: Every ID referenced by <link target="#s1 #t1"/> or @facs="#zone" must exist on an element in the loaded edition (status bar shows zero unresolved targets).
2. One color convention: Preserve semantic link cues—words (red), segments (green), sentences (dashed blue), and image regions (amber boxes).
3. Restraint in entity CSS: Use subtle underlines and hover provenance cues rather than distracting neon backgrounds.
4. Clean console check: Verify zero HTTP 404 errors and zero XML parser warnings in browser DevTools (F12).
