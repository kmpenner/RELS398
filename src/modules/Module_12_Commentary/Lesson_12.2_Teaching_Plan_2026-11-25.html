THE WEB ANNOTATION DIRECTIVE: INTEROPERABLE OPEN DATA

A scholarly edition should not remain trapped inside an isolated desktop file. By adopting the W3C Web Annotation Data Model, students publish machine-readable commentary that connects directly to digitized scans in remote archives and museum collections across the globe.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. The human gatekeeper: An algorithmic match is an empirical proposal, not a verified fact; students must audit every match against historical plausibility.
2. Stoplists are mandatory: Never execute raw text comparison without filtering out high-frequency grammatical stopwords.
3. Tripartite W3C structure: Every web annotation must contain an Annotation container, a Target, and a Body.
4. Resilient context selectors: Always include prefix and suffix inside your TextQuoteSelector so notes survive webpage redesigns.
5. Wednesday audit logging: Record all true positive and false positive discoveries in COMMENTARY.md to benchmark algorithmic performance against Tuesday's ground truth.
