Module 12: Digital Scholarly Commentary — Learning Objectives

By the end of this module, students will be able to:

  • Classify scholarly commentary into distinct categories: philological/linguistic, historical/contextual, and intertextual text reuse.
  • Construct stable xml:id anchors and encode commentary notes in TEI P5 using <standOff>, <interpGrp>, <note>, and @target.
  • Detect formulaic text reuse using stoplists, TF-IDF rarity weighting, and regex proximity searches across document collections.
  • Model linked annotations using the W3C Web Annotation Data Model, specifying targets, bodies, motivations, and TextQuoteSelector in JSON-LD.
  • Audit and vet AI-generated commentary notes with strict negative constraints, catching hallucinated citations, anachronisms, and fake treaty clauses.
