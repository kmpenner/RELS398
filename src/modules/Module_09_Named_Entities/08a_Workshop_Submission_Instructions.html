Submission Instructions

  1. Choose a passage containing 10 named entities.
  2. Manual: list each entity in a table in ENTITY_AUDIT.md with its type and one authority link (Wikidata, VIAF or GeoNames). If you checked and found no record, write “checked, none” — that earns full credit.
  3. spaCy and AI: run the passage through spaCy and through an AI model; add what each found to the table. Below it, give two counts per tool: how many of your 10 it found, and how many things it tagged wrongly.
  4. Merge: encode the merged result as entities_merged.xml with <persName>, <placeName>, <orgName> or <date> and @ref, and check it is well-formed. Test every AI-supplied link before you keep it.
  5. Submit ENTITY_AUDIT.md (table, counts, and a 150–250 word reflection at the end of the same file) and entities_merged.xml.
