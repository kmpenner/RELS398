THE DETERMINISTIC OBJECTIVE: SCALABLE PROCESSING AUDITED BY TRUTH

Hand-crafting entity markup works for twenty words; analyzing an archival corpus requires computational automation. Deterministic models and statistical sequence taggers provide reproducibility and scale. However, because modern models are trained on contemporary news, they suffer from Out-of-Vocabulary orthography, boundary slips, and type confusion. By benchmarking machine predictions against Tuesday's ground truth, students learn to audit computational tools scientifically.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Ground truth remains sovereign: Never alter Tuesday's manual ground-truth table to match the computer's mistakes. Discrepancies measure the algorithm's error rate, not human error.
2. Language-specific pipelines: Ace runs French SpaCy models (fr_core_news_sm); Andromeda and Olyvia run English models (en_core_web_sm). Never execute English pipelines on French text.
3. Token alignment gate: Ensure token counts remain aligned between manual and automated files. If the model merged or split tokens differently, diagnose the boundary error before scoring.
4. Assignment continuity: The accuracy metrics and discrepancy tables compiled today form the central empirical pillar of Assignment: Module 9, due Friday, November 6, at 11:00 PM.
