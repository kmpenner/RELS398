THE CONTINUOUS INTEGRATION OBJECTIVE: AUTOMATING EDITORIAL INTEGRITY

A mature digital edition relies on a dual-gate architecture: automated software verification guarantees syntactic and schema well-formedness on every commit, while human peer review audits paleographical fidelity and historical interpretation. Today students configure both gates.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Automated validation gate: Every push to main or pull request must trigger .github/workflows/validate.yml and pass with zero errors.
2. Dual-gate peer review: Reviewers must verify both automated CI status and human rubric fidelity (metadata, diplomatic accuracy, regularization, and entity links).
3. Constructive review tickets: Peer reviews must be submitted as actionable GitHub Issues or inline PR comments with specific evidence, not casual verbal notes.
4. Longevity awareness: All files must remain static TEI XML and CSS, adhering to The Endings Project principles without database dependencies.
5. Module 10 assignment deadline: Assignment: Module 10 (Consolidation & CI/CD) is due tonight, Friday, November 13, at 11:00 PM.
