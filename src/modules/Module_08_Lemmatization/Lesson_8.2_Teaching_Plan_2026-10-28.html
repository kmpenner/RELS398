THE DETERMINISTIC OBJECTIVE: SCALABLE PROCESSING AUDITED BY TRUTH

Hand-parsing works for twenty words; analyzing a complete archive requires computational automation. Deterministic NLP pipelines provide speed, reproducibility, and standard Universal Dependencies output. However, because modern tools are trained on contemporary data, they make systematic errors on historical documents. By measuring machine accuracy against Tuesday's ground truth, students learn to audit computational tools rigorously.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Ground truth remains sovereign: Never alter Tuesday's manual ground-truth table to match the computer's mistakes. The human ground truth is the benchmark; discrepancies measure the algorithm's error rate.
2. Language-specific models: Ace must run French models (fr_core_news_sm or French TreeTagger); Andromeda and Olyvia must run English models (en_core_web_sm). Never run English pipelines on French text.
3. Token alignment gate: Ensure token counts match between the manual table and automated output before calculating accuracy. If the computer merged or split tokens differently, diagnose the tokenization failure first.
4. Assignment continuity: The accuracy metrics and discrepancy tables produced today form the middle pillar of Assignment: Module 8 (Linguistic Markup), due Friday, October 30, at 11:00 PM.

nlp = spacy.load("en_core_web_sm")  # or fr_core_news_sm

doc = nlp(text)

print(f"{'Token':12} {'Lemma':12} {'UPOS':8} {'Deprel':8}")
print("-" * 44)
for token in doc:
    print(f"{token.text:12} {token.lemma_:12} {token.pos_:8} {token.dep_:8}")
