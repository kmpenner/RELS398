Module 08: Morphological Analysis & Lemmatization — Learning Objectives

By the end of this module, students will be able to:

  • Distinguish clearly between inflected surface tokens, dictionary headwords (lemmas), and morphological feature bundles (case, number, gender, tense, voice, mood).
  • Encode linguistic annotations within TEI XML using <w> elements with lemma=, pos=, and @ana attributes.
  • Deploy specialized NLP pipelines (such as CLTK, TreeTagger, and Stanza) to automate part-of-speech tagging and lemmatization on historical texts.
  • Model grammatical syntax using Universal Dependencies (UD) dependency relations and treebank structures.
  • Audit and benchmark neural LLM morphological taggers against a curated manual ground truth, evaluating out-of-vocabulary handling and hallucinated lemmas.
