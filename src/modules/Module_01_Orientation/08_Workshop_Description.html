Workshop: Your Project Repository & Witness README

Overview: Every assignment this term builds on one page of one historical document that you chose in Week 1. This workshop turns that choice into the first artifact of your edition: a Git repository you built from the command line, holding a README.md that identifies your witness, records the checks you made before committing to it, and states how the project will meet the FAIR principles.

You have probably already done parts of this. The workshop asks you to make it complete, verifiable, and visible in your commit history. Your header (Workshop 2) and your facsimile (Module 3) will draw on the facts you record here, so errors in this file travel.

What this workshop practises: the shell (mkdir, cd, echo, ls), plain-text Markdown, atomic Git commits with specific messages, and FAIR as a set of concrete decisions rather than a slogan.

Deliverables: your README.md, the output of git log --oneline, and a 200–300 word FAIR statement. Post them for peer review.

Deadlines: the submission and assessment dates shown in this workshop's Moodle settings.
