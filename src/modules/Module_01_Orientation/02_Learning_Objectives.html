Module 01: Orientation — Learning Objectives

By the end of this module, students will be able to:

  • Distinguish plain text formats from word-processor document binaries and articulate why plain text, open formats, and semantic markup are foundational for durable digital humanities scholarship.
  • Operate a modern digital scholar's workbench (VS Code, the terminal, Git version control, XML/TEI structures, Python scripting, and AI pair-programming) using the three-step comparative methodology (manual baseline → deterministic script → AI-assisted model).
  • Explain the FAIR principles — Findable, Accessible, Interoperable, Reusable — and evaluate tools, platforms, and research outputs against them.
  • Describe the standard scholarly edition workflow (cataloguing → images → transcription → reconciliation and normalization → collation → linguistic markup → translation and annotation → presentation) and situate each module of this course within it.
  • Select, verify, and record a primary manuscript passage — image, catalog identity, and difficulty — as the committed foundation for transcription, collation, encoding, and analysis throughout the term.
