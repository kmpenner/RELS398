Module 01: Orientation — Learning Objectives

By the end of this module, students will be able to:

  • Distinguish plain text formats from word-processor document binaries and articulate why plain text, open formats, and semantic markup are foundational for durable digital humanities scholarship.
  • Operate a modern digital scholar's workbench (VS Code, the terminal, Git version control, XML/TEI structures, Python scripting, and AI pair-programming) using the three-step comparative methodology (manual baseline → deterministic script → AI-assisted model).
  • Explain the distinction between visual rendering (graphemes) and underlying digital storage (Unicode code points), recognizing why visual identity does not guarantee computational identity in historical texts.
  • Analyze and normalize polytonic Greek character encodings (distinguishing NFC composed vs. NFD decomposed forms, UTF-8 byte streams, and line endings) to prevent silent corruption in computational collation and search.
  • Select and initialize a primary manuscript witness that will serve as the foundation for transcription, collation, XML encoding, and AI-assisted analysis throughout the term.
