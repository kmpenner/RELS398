THE AI STYLESHEET OBJECTIVE: RULES OVER DIRECT RENDERING

Never ask a large language model to render a historical document directly into HTML text. Directly generated pages drift, silently modernize archaic vocabulary, hallucinate expansions, or drop milestone line breaks. Asking the model to write an XSLT stylesheet constrains it to authoring executable transformation logic: an XSLT stylesheet is text-preserving and cannot invent words. Once verified, the stylesheet runs identically on every pass.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Ask for rules, never direct text: Prompts must request an XSLT 1.0 stylesheet based on the RENDERING.md decision table. Never paste raw text and ask the model to format it directly.
2. Commit unedited baseline first: The model's exact response must be committed as tei_to_html_ai_raw.xsl before any edits are made. Provenance requires recording what the model authored versus what the human scholar corrected.
3. Three points of comparison: Audit every AI rule against three standards: (a) RENDERING.md for editorial intent, (b) Wednesday's index_xslt.html for text fidelity, and (c) Tuesday's index_manual.html for visual styling.
4. Watch for XSLT 2.0 traps: Models frequently hallucinate XSLT 2.0 functions (string-join(), replace()) or xpath-default-namespace, which fail silently or crash in Python's lxml processor.

  • Baseline Integrity: tei_to_html_ai_raw.xsl is committed unchanged immediately upon model generation.
  • Side-by-Side Diff: Open index_xslt.html and index_ai.html in VS Code split view; use Compare Active File With... to highlight every divergence.
  • Targeted Edit: Modify only the audited file tei_to_html_ai.xsl to rectify errors, then re-run render.py.

Closing Understanding Check / Kahoot Fallback

  • Question 1: Why is an AI-generated XSLT stylesheet safer than asking an AI to output rendered HTML directly? (A stylesheet is text-preserving and cannot hallucinate or drift from the source XML).
  • Question 2: Why does xpath-default-namespace cause an empty page in lxml? (Python's lxml is an XSLT 1.0 processor and silently ignores the 2.0 namespace directive).
  • Question 3: What is an orphan template? (A template generated by the model that corresponds to no recorded decision in RENDERING.md).

Classroom Diagnostics & Cohort Guidance

Common Diagnostic Pitfalls

  • Silent XSLT 2.0 Crash: lxml.etree.XSLTApplyError thrown without naming the function. Search for string-join, matches, or tokenize and replace with recursive templates or simple loops.
  • Invented Class Names: The model generates creative class names like .treaty-heading or .decree-article instead of Tuesday's .tei-head. Audit and rename them to match the CSS.
  • Unescaped Entities: Model writes raw ampersands inside HTML text templates; replace with &amp; or wrap inside <xsl:text>.

Cohort Document Specifics

  • ACE · 1791 French Decree: Check whether the model handled uppercase accented characters properly or hallucinated French modernizations in output templates.
  • OLYVIA · Maud Lewis Letter: Check whether the model respected letter margins and salutation elements without dropping colloquial spacing.
  • ANDROMEDA · 1752 Treaty: Verify that the model preserved all treaty article numbers and did not discard thorn abbreviation markup.
