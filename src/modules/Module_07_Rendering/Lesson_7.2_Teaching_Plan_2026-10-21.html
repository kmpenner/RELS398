THE DETERMINISTIC OBJECTIVE: SCALABLE, REPEATABLE TRANSFORMATION

Hand-crafting HTML works for twenty lines; a complete historical document requires automation. XSLT and CETEIcean provide deterministic transformation: identical input into the same rules yields identical output every time. XSLT transforms TEI XML into HTML before publication (server-side/pre-build), whereas CETEIcean transforms TEI in the reader's browser. Both rely on the decision rules established in Tuesday's table.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Always prefix the TEI namespace: Every XSLT match must use the declared tei: prefix (xmlns:tei="http://www.tei-c.org/ns/1.0"). A bare match like match="p" will never fire on TEI XML, causing silent fall-through.
2. Prevent built-in fall-through: When an element has no template, XSLT's default rule outputs all text children as plain text. On <choice>, this erroneously glues original and regularized words together. Every element in the file must have an explicit template.
3. Preserve milestone and empty tags: Empty tags like <lb/> and <gap/> have no child text; without an explicit template, XSLT quietly deletes them entirely.
4. Output connects to Tuesday's CSS: The HTML generated by XSLT must use the exact class names defined on Tuesday so that diplomatic.css and reading.css style it seamlessly.

Starter Projection Skeletons & Live Reference

Starter Projection Card A: XSLT Root Shell & Namespaces

<?xml version="1.0" encoding="UTF-8"?>
<xsl:stylesheet version="1.0"
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
    xmlns:tei="http://www.tei-c.org/ns/1.0">
  <xsl:output method="html" encoding="UTF-8" indent="yes"/>

  <!-- Match root: build HTML wrapper and process body only -->
  <xsl:template match="/">
    <!DOCTYPE html>
    <html lang="en">
    <head>
      <meta charset="utf-8"/>
      <title><xsl:value-of select="//tei:titleStmt/tei:title[1]"/></title>
      <link rel="stylesheet" href="reading.css"/>
    </head>
    <body>
      <div class="edition-container">
        <xsl:apply-templates select="//tei:text/tei:body"/>
      </div>
    </body>
    </html>
  </xsl:template>
</xsl:stylesheet>

Starter Projection Card B: Choice & Milestone Templates

<!-- Structural elements -->
<xsl:template match="tei:p">
  <p class="tei-p"><xsl:apply-templates/></p>
</xsl:template>

<!-- Reading view: select regularized and expanded forms only -->
<xsl:template match="tei:choice">
  <span class="tei-choice">
    <xsl:apply-templates select="tei:reg | tei:expan | tei:corr"/>
  </span>
</xsl:template>

<!-- Milestone line breaks: prevent empty-tag deletion -->
<xsl:template match="tei:lb">
  <span class="tei-lb" data-n="{@n}"></span>
</xsl:template>

Python render.py Execution Script

#!/usr/bin/env python3
import sys
from lxml import etree

if len(sys.argv) < 4:
    sys.exit("Usage: python3 render.py <input.xml> <style.xsl> <output.html>")

xml_doc = etree.parse(sys.argv[1])
xslt_doc = etree.parse(sys.argv[2])
transform = etree.XSLT(xslt_doc)
result_doc = transform(xml_doc)

with open(sys.argv[3], "wb") as f:
    f.write(etree.tostring(result_doc, pretty_print=True, method="html"))
print(f"Rendered {sys.argv[3]} successfully.")

Closing Understanding Check / Kahoot Fallback

  • Question 1: What happens if an XSLT template matches "p" instead of "tei:p" on a TEI file? (It never matches, and text falls through unformatted).
  • Question 2: What happens to <choice> when no template matches it? (Both original and regularized words are output together into the text).
  • Question 3: How does CETEIcean differ from XSLT in where transformation takes place? (CETEIcean transforms in the client browser DOM; XSLT transforms ahead of time).

Classroom Diagnostics & Cohort Guidance

Common Diagnostic Pitfalls

  • Empty Output File: Usually caused by forgetting the tei: prefix on select="//tei:text/tei:body" in the root template, causing the body to be missed entirely.
  • Glued Choice Text: If text shows publickpublic, the <choice> template was omitted or failed to match, triggering built-in text fall-through.
  • Disappearing Line Numbers: If line numbers vanish, check that the <lb> template extracts @n via attribute value template data-n="{@n}".

Cohort Document Specifics

  • ACE · 1791 French Decree: Match French section headers and articles (tei:div[@type='article']); ensure accent entities in XML do not trigger parser errors in lxml.
  • OLYVIA · Maud Lewis Letter: Write specific templates for tei:opener, tei:salute, and tei:closer so that letter structure transforms into semantic divisions.
  • ANDROMEDA · 1752 Treaty: Write templates for tei:head and treaty numbered clauses; verify that thorn contractions (ye) expand cleanly to the in the reading output.
