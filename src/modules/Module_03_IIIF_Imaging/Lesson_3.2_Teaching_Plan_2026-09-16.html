WHY 3.1 AND 3.2 SHARE THIS HOUR: THE NUMBERS ARE THE SAME NUMBERS

The manual facsimile and the deterministic tools are not two topics. A <surface> is four numbers and a URL; a <zone> is four more. Today students first get those numbers by eye and by hand, then get them from the file with a tool that cannot guess. The comparison between the two is the week's Step 1 vs. Step 2 in miniature, and it sets up Friday, when an AI model proposes the zones. One exception, because the workshop requires it: the manifest is not taught, but every student must leave knowing they owe an answer to “does my repository serve IIIF?” — that is set as homework in the last slot, not lectured here.

Conversion: GIMP and IIIF give x,y,w,h. TEI wants ulx=x, uly=y, lrx=x+w, lry=y+h. Going the other way (TEI to an IIIF region string, if it ever comes up): x=ulx, y=uly, w=lrx−ulx, h=lry−uly → region="x,y,w,h".

Six Rules for a Usable Document Image

  1. Parallel. Keep the lens square to the page. A tilt makes a trapezoid (keystoning), and rectangular zones will no longer fit the lines.
  2. Even, diffuse light, from two sides at about 45°. A window with a sheet of paper as reflector works. Avoid hot spots and your own shadow.
  3. No flash. It causes glare on glossy paper and ink, and light exposure the object doesn't need. Glare that remains calls for cross-polarisation (3.1 §18).
  4. A ruler and a grey or colour reference go in the frame, at the same height as the page. Without them, pixels have no size and colours have no reference.
  5. The whole object, plus margin. Include the edges, since they are evidence. Fill the frame and don't use digital zoom.
  6. Keep the original. Save the highest-quality or RAW file untouched and work on copies. Name files by shelfmark and page (MSAm1118-3_338_r.jpg), not IMG_4471.

Handling: clean dry hands rather than cotton gloves for paper. Never force a binding open. No pens or drinks near the object.

Classroom Diagnostics

  • "Did not expect element facsimile": the block was placed inside <text> or before <teiHeader>. Move it between the two.
  • Zone extends past the surface: w,h were typed as corners, or the viewer's zoomed display size was read. Take the size from file.
  • Pointer to nothing: facs="diary_p1" is missing the #, or the xml:id is misspelt. The schema will not catch it, so check it by eye.
  • xml:id starting with a digit (338r) is invalid. Prefix it with a letter.
  • Pillow missing: pip install pillow. If that fails, use the file output and type the block from it; that is still deterministic.
  • Relative url breaks when the image isn't in images/ next to witness.xml. For a repository image, use its full https URL.
  • IIIF region vs. TEI zone confusion (if a student looks up a IIIF viewer's URL): IIIF's region is x,y,width,height, not the ulx,uly,lrx,lry corner pairs TEI uses. Don't paste one into the other unconverted.
