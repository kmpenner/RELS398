WHAT THIS HOUR IS FOR: THE MODEL MAKES TWO KINDS OF CLAIM AND ONLY ONE IS CHECKABLE

The teaching content for AI imaging is on Moodle in Lesson 3.3 — segmentation, baseline detection, super-resolution, hallucination risk, the black-box problem. Do not lecture it. The one idea that has to land in the room is this: a model returns measurements (four numbers for a box) and judgements (that this box is a seal, that this region matters) in the same confident sentence, and the students already hold a deterministic answer for the first kind and nothing but their own scholarship for the second. Projection: The Zone Prompt (paste this)

# attach the page image, then:
You are looking at one page of a historical
document. Identify the three most significant
visual features on the page (for example a
heading, a signature, a seal, a stamp, a
correction, or an area of damage).

For each, return ONE line, nothing else:
  label | x,y,w,h | one-sentence reason

Coordinates in pixels, origin top-left,
y increasing downward, for the image as sent.
State the pixel dimensions you assumed.

Why ask for the assumed dimensions: models silently work from a resized copy. If it reports a width that is not your file's width, every coordinate is scaled and the comparison is meaningless until you rescale. This is the single most common cause of a “wildly wrong” box — check it before concluding the model failed.

Convert and Score

# same tool as Wednesday, AI numbers in
python3 labs/make_surface.py images/diary_p1.jpg \
  --zone 315,255,1170,168 > facs_ai.xml
# the ruler, for the same feature
diff facs_tool.xml facs_ai.xml

Fallback if the model returns no usable coordinates: ask it instead to name and describe the three features in words, then have the student locate them in GIMP. The judgement question survives intact, which is the part that is graded.

The Reflection Prompt (give verbatim)

300–500 words. Where did your eye disagree with the tool, and which of you was wrong? Report your coordinate numbers and say what caused each discrepancy. Then address the part no tool settles: how did you decide which three regions deserved a zone, and what can a reader check because you drew them?

Today adds a third column to that question. A strong answer now also says what the model proposed, what was accepted, corrected or rejected, and how that decision was made.

Classroom Diagnostics

  • Every AI box is off by the same factor (e.g. all roughly half): the model worked from a resized copy. Compare its stated dimensions to file, then scale. Not a hallucination — an arithmetic error, and a good one to catch publicly.
  • Boxes returned as ulx,uly,lrx,lry already: models are inconsistent about this. Check whether the third number is smaller than the first; if it is not, it is probably a corner, not a width.
  • A confident label for a feature that is not there — a “wax seal” on a photocopy, a “signature” on a printed name. This is §26 in the flesh. Stop the room for it if it happens.
  • Zone extends past the surface: same failure as Wednesday. lrx/lry cannot exceed the surface's.
  • Student has no digital image at all (reading-room-only object): they score the model on the class diary page instead, and write the provenance record about why no image exists. That is a legitimate finding and a complete submission.
  • Model refuses the image (rights, faces, handwriting policy): record the refusal verbatim in the reflection. An unusable tool is a result about the tool.
