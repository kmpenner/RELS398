Module 03: IIIF Imaging & Facsimiles — Learning Objectives

By the end of this module, students will be able to:

  • Deconstruct the International Image Interoperability Framework (IIIF) Image API syntax ({scheme}://{server}/{prefix}/{identifier}/{region}/{size}/{rotation}/{quality}.{format}) for parametric image retrieval.
  • Construct and validate IIIF Presentation API 3.0 Manifests structuring complex manuscript sequences, Canvases, AnnotationPages, and Painting annotations.
  • Link digital image coordinates to structured transcription text using TEI <facsimile>, <surface>, and <zone> elements linked via @facs XML attributes.
  • Deploy client-side digital workspace viewers (Mirador and Universal Viewer) to conduct comparative multi-witness side-by-side paleographical collation.
