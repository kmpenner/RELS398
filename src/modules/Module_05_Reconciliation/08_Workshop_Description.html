Workshop: Pair Reconciliation & Consensus Ground Truth

Overview: In this workshop, you will swap your blind diplomatic transcription with a peer. You will run an automated diff between both transcriptions, identify every point of divergence, return to the high-resolution IIIF facsimile to adjudicate each difference, and establish an agreed consensus ground truth.
