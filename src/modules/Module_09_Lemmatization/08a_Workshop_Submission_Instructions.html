Submission Instructions

  1. Select 20 consecutive words from your primary manuscript witness.
  2. Tier 1 (Manual): For each word, look up its canonical dictionary lemma and provide a full morphological breakdown (part of speech, gender/number/case or tense/voice/mood) in a Markdown table.
  3. Tier 2 (NLP Engine): Run the excerpt through a computational tagging script (using Python CLTK, Stanza, or TreeTagger) and record the predicted lemmas and POS tags.
  4. Tier 3 (LLM): Query an LLM with a structured system prompt requesting JSON or TEI <w> tags with lemma and pos attributes.
  5. Encode the excerpt in TEI XML using <w lemma="..." pos="...">token</w> elements based on your verified ground truth.
  6. Submit your TEI file, your Python/prompt script, and a 300–500 word reflection analyzing which morphological categories caused the highest failure rate in the automated pipelines.
