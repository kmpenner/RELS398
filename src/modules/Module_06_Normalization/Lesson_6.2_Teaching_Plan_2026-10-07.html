LESSON 6.2 CORRECTED ON OCT 3: TWO RULES WERE WRONG

1. Thorn (section 15): the lesson taught \b([Yy])e\b → <expan>$1he</expan>. A backreference copies the captured letter, so that produces yhe and Yhe, not the/The. The source now teaches one rule per case (\bye\b → the, \bYe\b → The, Match Case on), and the ledger example and Python recipe match.
2. French -oit (section 16): VS Code's engine treats é as punctuation. \b(\w+)oit\b matches only toit inside étoit and splits the word; \bétoit\b never matches. The source now teaches (?<!\p{L})(\p{L}+)oit(?!\p{L}). Python's re is Unicode-aware, so the script route was always fine.

THE REGEX OBJECTIVE: A RULE IS ONLY AS GOOD AS ITS FALSE POSITIVES

Translating the ledger into patterns audits the ledger: every vague rule surfaces as a pattern that cannot be written, and every unstated exception surfaces as a false positive. Precision outranks recall. A rule that misses three variants leaves them for review; a rule that corrupts one innocent word has damaged the edition. Teach step-and-replace, never a blind Replace All.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Start from the raw excerpt, not the manual file: transcription_reconciled_regex.xml is a fresh copy of the same 20 lines of transcription_reconciled.xml. Running regex over Tuesday's already-tagged file nests <choice> inside <orig> and makes the diff meaningless.
2. No bare wildcards in XML: no .* or .+ anywhere. Use \w+, \p{L}+ or [^<>]* so a pattern cannot cross a tag.
3. Step through matches before replacing: press Enter to inspect, Replace one at a time; Replace All only after five or six clean matches of that one rule.
4. Words split by <lb/> stay manual: they will not match, and that is expected. Count them as false negatives; do not write a pattern with a hard-coded line number.

Pattern Reference for the Live Demo

Whitelisted Orthographic Rule (R-01)

Find:    \b(publi|traffi)ck\b
Replace: <choice><orig>$1ck</orig><reg
         resp="#editor">$1c</reg></choice>

Thorn: One Rule per Case (Match Case on)

Find:    \bye\b
Replace: <choice><abbr>ye</abbr><expan
         resp="#editor">the</expan></choice>
Find:    \bYe\b      ... <expan>The</expan>

French: Unicode-Aware Boundaries

Find:    (?<!\p{L})(ét|av|fais|déroge)oit(?!\p{L})
Replace: <choice><orig>$1oit</orig><reg
         resp="#editor">$1ait</reg></choice>

XML-Safe Golden Rule

.*     ->  [^<>]*    stay inside text nodes
.+     ->  \w+        stop at tags and punctuation
ye     ->  \bye\b     never match type="..."

Cohort Specific Regex Guidance

JAY · Emily Dickinson Poem (MS Am 1118.3)

  • Few rules, all explicit: \b([Oo])pake\b and \b([Ee])therial\b are word-specific and cannot misfire. A two-rule ledger at 0 FP is a good result.
  • The exclusions are the test: no rule may touch a capital or a dash. If a rule changes Soul or Door, the diff shows it as an FP against Tuesday's file, which is the right evidence for the reflection.

ACE · French Revolutionary Decree (1791)

  • Accents break \b in VS Code: use (?<!\p{L}) and (?!\p{L}) around any pattern that touches an accented word. Have Ace try \bétoit\b first and see zero matches; it makes the point.
  • The droit trap: a general -oit rule regularizes droit and étroit. Whitelist the verb stems in the 20 lines. Long-s: one global ſ → s pass only if the policy declared it in the header.

OLYVIA · Maud Lewis Letter (20th c. Cursive)

  • One rule per word: \b([Aa])llways\b, \b([Uu])ntill\b, \b([Tt])ruely\b. Here the captured letter is reused unchanged, so $1 is safe, unlike thorn.
  • The wont trap: \b([Dd])ont\b is safe; a matching rule for wont is not, because wont is a word. Step through it. No rule touches we was.

ANDROMEDA · 1752 Peace and Friendship Treaty

  • Match the transcription as it stands: if Week 4 encoded y<hi rend="superscript">e</hi>, the pattern must include the <hi> tag literally (section 15). Govr and Esqr are word-specific rules.
  • Order matters most here: run the abbreviation rules before the casing rule, and make the casing rule a whitelist of nouns (\b(Articles|Peace|Treaty)\b), never "every capital", or it lowercases names and Ye.
