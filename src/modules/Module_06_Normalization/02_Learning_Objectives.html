Module 06: Orthographic Normalization — Learning Objectives

By the end of this module, students will be able to:

  • Distinguish between meaningful textual variation and phonological or orthographic drift (such as 18th-century French Voltairean spelling reforms, early modern English spelling fluidity, and vernacular phonetics).
  • Encode diplomatic readings and normalized editorial regularizations using TEI <choice>, <orig>, <reg>, <abbr>, and <expan> markup with explicit @resp attribution.
  • Construct and execute deterministic regular expressions in the VS Code editor (and an optional Python script) utilizing word boundaries (\b) and capture groups to automate rule-based normalization safely.
  • Audit AI-generated normalization outputs against a verified manual ground truth to calculate error rates, diagnose "hypercorrection", and protect dialectal and authorial voices.
