THE CAPSTONE ARCHIVAL DIRECTIVE: DURABLE SUSTAINABILITY

A digital scholarly edition must be built to last. Reject server-side dependencies and fragile databases; embrace minimal computing, static file bundling, cryptographic checksums, and permanent Zenodo DOIs.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Multi-modal compilation: Editions must compile into web, offline standalone, and print PDF formats from a single master XML file.
2. Minimal computing architecture: All web deliverables must run as static files on GitHub Pages without server-side database requirements.
3. Cryptographic data integrity: Every release package must include a verified CHECKSUMS.txt manifest generated with SHA-256.
4. Transparent AI disclosure: Full disclosure of all language models, prompt workflows, and human-in-the-loop verification protocols.
5. Strict evaluation timeline: Assignment 12 is due tonight at 11:00 PM; the Capstone Portfolio is due during the Exam Period (Dec 10–19).
