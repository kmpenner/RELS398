THE DESIGN STUDIO DIRECTIVE: DECLARATIVE SEPARATION

Never hard-code visual presentation into TEI XML. Instead, use declarative <model> rules inside an ODD specification to bind semantic elements to abstract behaviors and modular CSS classes.

INVIOLABLE PEDAGOGICAL BOUNDARIES

1. Declarative modeling over bespoke code: Avoid fragile procedural stylesheets; declare abstract behaviors in ODD.
2. Clean typographic restraint: Avoid distracting neon highlights; use subtle muted tones and interactive tooltips for named entities.
3. Rigorous documentary styling: Preserve physical cancellations and additions with strikethrough and superscript styles rather than erasing them.
4. Responsive design: Layouts must adapt gracefully from widescreen side-by-side panes to stacked vertical views on mobile devices.
5. Universal accessibility: Provide semantic HTML landmarks, descriptive alt text for manuscript images, and full keyboard navigation.
