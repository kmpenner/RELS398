Module 13: Digital Edition Publication & Archiving — Learning Objectives

By the end of this module, students will be able to:

  • Formulate a comprehensive scholarly Editorial Declaration in TEI <editorialDecl>, detailing explicit policies for transcription, normalization, rendering, and named-entity markup.
  • Document and defend the textual transmission and documentary history of your primary witness within the scholarly introduction.
  • Author a TEI Processing Model ODD customization, mapping semantic markup to multi-target presentation behaviors (<model>, @behaviour, @predicate).
  • Compile multi-modal distribution packages (interactive web editions, responsive offline HTML players, and print-ready PDF/A volumes via CSS Paged Media) from a single canonical TEI XML master.
  • Implement multi-tiered open access licensing (Creative Commons and open source software licenses) and deposit archival edition portfolios according to FAIR data principles with persistent Zenodo DOIs.
