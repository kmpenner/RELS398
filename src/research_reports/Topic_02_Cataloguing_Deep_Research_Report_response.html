Executive Summary & Historical Foundations

Manuscript cataloguing relies on structured data schemas to formalize codicological descriptions, providing a baseline for downstream encoding and evaluating AI-generated metadata. Historically, descriptions transitioned from unstructured prose in print catalogs to highly structured digital formats. For example, the Oxford Medieval Manuscripts project digitizes finding aids using TEI P5 XML guidelines to ensure robust, rule-based validation. Concurrently, the semantic web utilizes Resource Description Framework (RDF) models, such as the CIDOC Conceptual Reference Model (CRM) and FRBRoo, to map event-centric manuscript histories and migrations. By establishing rigid computational ontologies, these structured schemas provide the necessary architecture for global interoperability, machine reasoning, and discovery.

Comparative Methodological Evaluation

The shift from manual encoding to Artificial Intelligence (AI) generation introduces both massive efficiencies and critical structural risks.

  • Manual TEI XML validation guarantees structural integrity but is highly labor-intensive, challenging the sustainability of massive digitization projects.

  • AI automation using Large Language Models (LLMs) accelerates text extraction but introduces XML validation failures, such as generating invalid copyright characters or incorrectly nesting the <langUsage> tag.

  • Comparative LLM testing reveals that Claude 3.5 Sonnet generates perfectly valid TEI files by adhering strictly to predefined reference files (like a macro.xml document).

  • Conversely, ChatGPT-4 occasionally hallucinates XML structures but excels at recognizing and encoding entities independently of reference files.

  • Integrating computer vision (e.g., YOLOv11) with semantic knowledge graphs allows for the iterative extraction of nested visual features (like text within seals), dynamically linking findings to expanding RDF ontologies.

Real-World Digital Edition Case Studies

Current digital scholarship demonstrates the powerful synergy between semantic frameworks and AI models.

  • Mapping Manuscript Migrations (MMM): This platform harmonizes disparate datasets (Bibale, SDBM, Oxford) into a global RDF knowledge graph utilizing an event-centric FRBRoo model.

  • Digital Scriptorium (DS) 2.0: Utilizing Wikibase, DS 2.0 aggregates U.S. manuscript metadata into a lightweight, object-centric Linked Open Data model linked directly to authorities like FAST and Wikidata.

  • PubCiNET: Investigating Italian intellectuals' correspondence, this project uses LLMs for automated TEI-XML encoding, relying on structured macro.xml files to accurately resolve entities across multiple archives.

Pedagogical Takeaways & Synthesis for Digital Editors

I completely understand how daunting it is to transition from traditional, narrative-based cataloguing to strict digital encoding; it often feels like having to learn a completely alien language. However, it is essential to ground your expectations in reality: AI cannot magically bypass the hard work of semantic structuring. When designing a TEI Header or RDF graph for historical manuscripts, follow these steps:

  • Establish a highly structured, rule-based baseline schema first to ensure cross-institutional data interoperability.

  • Construct standardized local authority files (e.g., macro.xml) aligned with global authorities (VIAF, Wikidata) prior to running AI extraction models.

  • Implement hybrid validation workflows where AI outputs are strictly vetted against predefined schemas (like RNG/XSD) to mitigate hallucinated or malformed records.
