# 00_Syllabus_and_Admin

Syllabus, schedule, course proposal forms, teaching notes, and other
administrative documents you author.

**Format convention: HTML is canonical.** Course documents are authored and
maintained as `.html` — machine-editable, diffable in git, readable by every
downstream tool. `.pdf` and `.docx` are derived artifacts generated from the
HTML, never hand-edited in parallel. If the two disagree, the HTML is right and
the derivative gets regenerated.

Student data (grades, submissions) does **not** go here — it goes in
`private/` at the repo root, which is git-ignored and excluded from the
Drive mirror.
